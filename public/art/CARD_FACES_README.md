# kortn card faces

- 53 transparent PNG files, each 500×700 pixels.
- Location: `faces/`
- Filename pattern: `<suit>-<rank>.png`
- Suits: `clubs`, `diamonds`, `hearts`, `spades`
- Ranks: `2`–`10`, `11` = Jack, `12` = Queen, `13` = King, `14` = Ace
- Joker: `faces/joker.png`
- `card-faces-manifest.json` contains the complete machine-readable mapping.
- `card-faces-contact-sheet.jpg` is a visual proof sheet only and is not required at runtime.

The PNG canvas has transparent rounded corners. All cards use the same 5:7 aspect ratio and the same worn indigo, maroon, aged-bone, sage, and tarnished-gold visual system as the matching card backs.
